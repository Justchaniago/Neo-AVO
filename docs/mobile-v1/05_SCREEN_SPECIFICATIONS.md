# Neo AVO Mobile v1 — Screen Specifications

## M01 Overview
Purpose: immediate situational awareness. Priority: Global State → Attention → Infrastructure → Recent Activity. States: normal, active incident, degraded infra, stale, offline, loading.

## M02 Projects
Cards show name, environment, three health dimensions, last activity, next expected execution if applicable.

## M03 Project Detail
Top health summary then last success, next expected execution, attention, dependencies, repository, timeline, commands.

## M04 Incidents
Tabs: Active, Resolved, All. Cards show severity, project, title, status, time, occurrence count when relevant.

## M05 Incident Detail
Severity/status/time → What Happened → Business Impact → Machine Evidence → AI Assessment → Recommended Investigation → Repository → Dependencies → Recovery → Timeline → Technical Details. Actions are lifecycle-aware.

## M06 Infrastructure
Host/provider/health/freshness; current resources; history; services; pressure episodes; blast radius; timeline.

## M07 Activity
Cross-project operational timeline with bounded filters.

## M08 Intelligence
Recent analyses, status, model, confidence, project/incident, usage metadata where available.

## M09 Agents
Agent/service, project, current state, last activity.

## M10 More/Settings
Secondary navigation and existing settings.

## M11 Global Search
Projects, incidents, activity, repository references where supported. Group by type.

## M12 Command Confirmation
Bottom sheet showing command, target, scope, date, side effect, cancel/confirm.
