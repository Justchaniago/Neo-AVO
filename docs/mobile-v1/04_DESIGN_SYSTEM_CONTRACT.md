# Neo AVO Mobile v1 — Design System Contract

## Authority
Desktop Neo AVO is the visual source of truth.

## Shared DNA
Preserve color tokens, fonts, typography character, uppercase micro-labels, borders, radius, buttons, badges, status semantics, iconography, spacing rhythm, editorial/industrial identity.

## Color
Healthy green/lime; warning amber; failure coral/red; AI purple; neutral surfaces cream/off-white/white/ink. Large colored surfaces only when they communicate active status/attention.

## Typography
Same font stack. Mobile may adjust scale but not invent a new typography system.

## Cards
Same card/border language; mobile may use compact/full-width composition.

## Touch
Aim for ~44px minimum hit area where practical. No hover-only control.

## Bottom Navigation
Use existing palette/icon style, safe-area padding, and obvious active state.

## Motion
Restrained, typically 150–250ms. No decorative portfolio-style motion.

## Charts
Simple, restrained, gaps for missing data, zero remains zero, stale/unknown not shown as healthy.

## Shared Primitives
StatusBadge, HealthIndicator, SeverityBadge, Metric, Time/Freshness, IncidentState, EmptyState, LoadingSkeleton.
