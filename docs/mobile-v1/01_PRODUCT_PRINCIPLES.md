# Neo AVO Mobile v1 — Product Principles

## Operational Mental Model
**Observe → Understand → Investigate → Act → Verify**

- Observe: Is everything okay?
- Understand: What changed and what is affected?
- Investigate: What does machine evidence say, and what does AI infer?
- Act: What safe bounded action should I take?
- Verify: Did recovery actually occur?

## Signal Before Detail
Priority: status → severity → impact → action → evidence → technical depth.

## Progressive Disclosure
Summary → Business Impact → AI Assessment → Recommended Action → Evidence → Repository → Dependencies → Timeline → Technical Details.

## Status Semantics
Green = healthy, amber = warning, coral/red = failure, purple = intelligence, neutral = informational. Color is information, not decoration.

## Native-Feeling Web UX
Use bottom navigation, full-screen details, bottom sheets, large touch targets, safe-area support, sticky actions, and no hover-only controls. Do not imitate platform chrome unnecessarily.

## Action Discipline
Read-only actions may be immediate. Externally visible or mutating actions require explicit confirmation.

## Honest Uncertainty
Missing telemetry is not healthy. Stale is not live. Correlation is not causation. AI hypotheses are not machine facts. Client offline is not server offline.

## Desktop Visual Authority
Desktop defines the visual identity. Mobile may change composition, order, navigation, interaction, and disclosure—not the design language.
